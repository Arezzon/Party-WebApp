# Quickstart: перевірка модерації

## Передумови

- Node ≥22.23.4, встановлені залежності (`npm install`).
- Сервер запущено з тим самим `DATABASE_PATH`, що й у демо.
- Модератор: `arsen@tusivka.local` / `Kodiaq2026!` (або адреса з `MODERATOR_EMAILS`).

## Кроки

1. `npm test && npx astro check && npm run build` — усе зелене.
2. Увійти як звичайний користувач (`maryna@tusivka.local` / `Tusivka2026!`), двічі надіслати скаргу на коментар → у БД один `open` запис.
3. Увійти як модератор, відкрити `/moderation` → скарга в черзі з текстом, подією, Автором і причиною.
4. Натиснути «Відхилити» → скарга зникає з черги, коментар лишається.
5. Створити нову скаргу, натиснути «Видалити коментар» → коментар зникає зі сторінки події, черга порожня.
6. Спробувати відкрити `/moderation` як звичайний користувач → 403.
7. `BASE_URL=http://127.0.0.1:4322 node tests/self-audit.mjs` → `SELF-AUDIT OK`.

Деталі полів і статусів — у [data-model.md](./data-model.md), контракти — у [contracts/moderation-api.md](./contracts/moderation-api.md).
