# Contracts: Moderation API

Усі мутації захищені глобальним Origin/CSRF middleware. Відповіді мутацій — `303` на
відповідну сторінку; помилки — дружні HTML/JSON з кодом 401/403/404/400.

## POST /api/comments/:id/report

Автор: залогінений учасник.

- Body: `reason` (1–500 символів), опційно `Idempotency-Key`.
- 401 — без сесії; 404 — коментар не знайдено або приватна подія без інвайту; 400 — порожня/довга причина.
- 303 — скаргу створено **або вже існує відкрита**. Повтор не створює дубль.

## POST /api/comments/:id/delete

Автор: автор коментаря або автор події.

- 401/403/404 — як і раніше.
- Якщо `report=1` або у тілі `report: true`, і діє автор події → додається `ModerationAction` з підставою.

## GET /moderation

Автор: модератор. HTML-черга відкритих скарг; немедодатор → 403.

## POST /api/moderation/:id/dismiss

Автор: модератор. Позначає скаргу `dismissed`, пише `ModerationAction`, коментар лишається.

## POST /api/moderation/:id/delete

Автор: модератор. Видаляє коментар, пов'язані скарги зникають каскадом, пише `ModerationAction`.

## GET /api/moderation/reports

Автор: модератор. JSON-список відкритих скарг (reserved для майбутніх клієнтів).
