# Quickstart: перевірка «Тусовки»

**Feature**: 001-tusivka-events

## Prerequisites
- Node ≥22.23.4 (проєктний Node уже в `node_modules/.bin/node`; додайте `export PATH="$PWD/node_modules/.bin:$PATH"`).
- npm install — вже виконано.

## Запуск
```bash
npm run dev        # http://localhost:4321
npm test           # автотести (6 файлів)
npm run build      # astro build
npx astro check    # 0 errors
```

## Сценарії перевірки (ручні)

### 1. Реєстрація/вхід/вихід
1. Відкрийте `/register` — поруч кнопки посилання «Політика конфіденційності».
2. Спробуйте пароль «1» → 400. Зареєструйтесь із валідними.
3. 10 невдалих входів → 429.
4. Вихід → ада cookie не відкриває `/profile` (302).

### 2. Подія + обкладинка
1. `/events/new` → назва, опис, дата через місяць, places=10, PNG обкладинка, visibility=public.
2. Подія на головній. Обкладинка віддається як `image/webp` + `nosniff`.
3. Спробуйте places=0 / дата 9999 → 400.

### 3. Запис і коментарі
1. Другий користувач тисне «Іду» → places 10→9; повтор → без дубля.
2. Коментар `<img src=x onerror=...>` показується текстом.
3. 20 паралельних «Іду» на places=1 → 1×303, 19×400.

### 4. Приватна подія
1. Створіть private подію; скопіюйте invite URL.
2. Анонім/без інвайту → 404 на сторінку, обкладинку, запис, коментар; на головній немає.
3. За інвайтом → доступ.

### 5. Профіль і дані
1. `/profile` — 2 списки. Змініть ім'я → скрізь нове.
2. Видаліть акаунт → сесія мертва, події/RSVP зникли, коментар «Знайомець».

### 6. Адаптив
1. Ширина 375px — шапка без переносів по складах.
