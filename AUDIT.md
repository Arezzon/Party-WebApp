# Аудит і перебудова «Тусовки» на React Bits

Дата: 2026-11-24

## Що знайшов

1. **Дублювання навігації.** Головна мала власну inline-шапку, `Header.astro` існував окремо, Layout використовував третій варіант. Один і той самий сайт мав три різні шапки.
2. **Кастомна розмітка там, де є готові компоненти.** Пошук, список подій, картки, кнопки, підвал і навігація були написані руками попри наявність у реєстрі React Bits готових `CurvedInput`, `AnimatedList`, `SpotlightCard`, `SpecularButton`, `GlassIcons`, `PillNav`.
3. **Сторінки без `global.css`.** `rules.astro` і `profile.astro` не імпортували глобальні стилі, через що Tailwind-класи не застосовувалися, а обгортка ефектів стояла в потоці й відсувала контент на ~1600px вниз.
4. **CSP різав гідрацію.** Без `script-src 'unsafe-inline'` Astro-острівці не оживали: SSR-HTML був, але React не запускався.
5. **Динатичні children в Astro-слоті губилися.** `GlitchText` з рядком-виразом як child рендерив порожній текст після гідрації.
6. **Ретард із тунелем.** `localtunnel` перестає форвардити після рестарту локального сервера — потрібно перезапускати тунель і перевіряти публічний GET/POST.

## Що зробив

Всі сторінки тепер працюють через єдиний `Layout`:

- **Навігація** — `PillNav` (з неоновим логотипом `NeonLogo` усередині).
- **Підвал** — `GlassIcons`.
- **Заголовки/підзаголовки** — `SplitText` (blur-в'їзд), `DecryptedText` (розшифрування), `ShinyText` (біжуче світло), `GlitchText` (RGB-глітч результату пошуку).
- **Пошук** — `CurvedInput`.
- **Списки подій/учасників** — `AnimatedList` із пружною анімацією.
- **Картки** — `SpotlightCard` + `BorderGlow`.
- **Лічильники місць** — `Counter`.
- **Кнопки у формах** — `SpecularButton`.
- **Профіль** — `ProfileCard`.
- **Фон** — `Aurora`, `DotGrid`, `Noise`, `ClickSpark`, `HoloMosaic`, `NeonGlyphs`.

Для передачі серіалізованих даних у React-острівці додано тонкі TSX-обгортки в `src/components/bits/`: `SiteNav`, `HeroText`, `PromoBanner`, `EventBrowser`, `FooterBits`, `ProfileBits`, `EventDetailBits`.

## Що лишилося нативним (свідомо)

- Поля багатоколонкових форм (реєстрація, подія, коментар, профіль) — у React Bits немає готового багатопольового form-компонента; доступний лише однопольовий `CurvedInput`. Кнопки в цих формах уже з React Bits.
- Юридичний текст правил і політики — звичайна семантична розмітка: текстові компоненти бібліотеки призначені для ефектів, а не для абзаців закону.
